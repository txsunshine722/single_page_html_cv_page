# Single-Page HTML CV

## Project Overview
This project is a **single-page CV (Curriculum Vitae)** built using only **HTML**. It showcases my background in cybersecurity, education, skillsm, and professional experience in a clean, structured format using semantic HTML.

The focus of this project is on content structure and accessibility, with styling to be added later using CSS.

##  SEO Meta Tags
Example:
```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Sarah Williams - Cybersecurity student CV">
<meta name="author" content="Sarah Williams">
```

---

##  Open Graph (OG) Tags
```html
<meta property="og:title" content="Sarah Williams - CV">
<meta property="og:description" content="Cybersecurity student showcasing skills and experience">
<meta property="og:type" content="website">
<meta property="og:url" content="https://yourwebsite.com">
<meta property="og:image" content="https://yourwebsite.com/preview.jpg">
```
